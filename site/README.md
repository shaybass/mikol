# OYA · יזמות צעירה — אתר

אתר סטטי, מודרני ומאוחד עבור **OYA** (www.oya.org.il), המשלב את נישת ההאקתונים
(hackathon.oya.org.il) כחלק ממותג אחד.

## מבנה

```
site/
├── index.html          # האתר הראשי של OYA (בית, אודות, תוכניות, הצלחות, צוות, צור קשר)
├── hackathon.html      # נישת ההאקתונים — מיתוג נפרד, חלק מאותה מערכת עיצוב
└── assets/
    ├── css/style.css   # מערכת עיצוב משותפת (RTL, טוקנים, קומפוננטות, אנימציות)
    └── js/main.js      # אינטראקציות: reveal בגלילה, מוני ספירה, ניווט מובייל, FAQ
```

## הרצה מקומית

זהו אתר סטטי לחלוטין — אין תלות בשרת או ב-build. אפשר פשוט לפתוח את
`site/index.html` בדפדפן, או להריץ שרת סטטי קטן:

```bash
cd site
python3 -m http.server 8080
# ואז לגלוש אל http://localhost:8080
```

## פריסה (Deployment)

מכיוון שהכל סטטי, אפשר לפרוס לכל אחסון סטטי:

- **Netlify / Vercel / Cloudflare Pages** — הצביעו את ה-root אל תיקיית `site/`.
- **GitHub Pages** — הגישו את התיקייה כ-`site/` (או העבירו אותה ל-root/`docs/`).
- **תת-דומיין ההאקתון** — הצביעו את `hackathon.oya.org.il` אל אותו אתר;
  `hackathon.html` הוא דף הנחיתה של הנישה. לחלופין אפשר ליצור redirect
  מ-`hackathon.oya.org.il` אל `/hackathon.html`.

## עיצוב

- **RTL מלא**, עברית, גופן Heebo.
- **מערכת צבעים** מבוססת אינדיגו · סגול · תכלת · אלמוג עם גרדיאנטים חיים.
- **רספונסיבי** לחלוטין (דסקטופ / טאבלט / מובייל).
- **ללא תלויות חיצוניות** מלבד Google Fonts; האייקונים הם inline SVG.

## תוכן

התוכן מבוסס על הפעילות האמיתית של OYA: מרכזי יזמות בית ספריים, האקתונים,
אליפויות סטארטאפ (יבנה 2050), MoveTeen, סיורי הייטק, והצלחות אמיתיות
(למשל Calmloop). עדכנו נתונים, קישורים וכתובות מייל לפי הצורך.
